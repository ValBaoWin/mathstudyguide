Functions

Defining, graphing, and transforming functions. The foundation of all chapters ahead.

2.1Functions▶

Key Concepts

  • A function is a rule assigning exactly one output to each input
  • Notation: f(x), g(x) — f(x) is the output when input is x
  • Domain: all valid inputs; Range: all possible outputs
  • Vertical Line Test: a graph is a function if every vertical line hits it at most once
  • Difference Quotient: [f(x+h) − f(x)] / h — slope of a secant line
💡

If you see a square root or fraction, find the domain by setting the radicand ≥ 0 or denominator ≠ 0.

2.2The Graph of a Function▶

Key Concepts

  • Reading domain/range from a graph (x-extent and y-extent)
  • x-intercepts (zeros): where f(x) = 0; y-intercept: where x = 0
  • Graph can show where a function is positive or negative
2.3Properties of Functions▶

Key Concepts

  • Increasing: f(a) < f(b) when a < b; Decreasing: f(a) > f(b) when a < b
  • Even function: f(−x) = f(x) → symmetric about y-axis
  • Odd function: f(−x) = −f(x) → symmetric about origin
  • Local max/min: turning points where function changes direction
2.4Library of Functions▶

Parent Functions to Memorize

  • Constant: f(x) = c (horizontal line)
  • Linear: f(x) = x; Quadratic: f(x) = x²; Cubic: f(x) = x³
  • Square root: f(x) = √x; Cube root: f(x) = ∛x
  • Absolute value: f(x) = |x|; Reciprocal: f(x) = 1/x
📌

Know the shape, domain, and range of every parent function cold — transformations in 2.5 build on all of them.

2.5Graphing Techniques & Transformations▶

Transformation Rules

  • Vertical shift: f(x) + k → up k; f(x) − k → down k
  • Horizontal shift: f(x − h) → right h; f(x + h) → left h
  • Vertical stretch: a·f(x), |a| > 1 stretches; 0 < |a| < 1 compresses
  • Reflect over x-axis: −f(x); over y-axis: f(−x)
  • Piecewise functions: different formulas for different parts of domain
General Form

g(x) = a · f(x − h) + k
h = horizontal shift, k = vertical shift, a = stretch/reflect

2.6Mathematical Models & Building Functions▶

Key Concepts

  • Setting up functions to model real-world relationships
  • Express one variable in terms of another using constraints
  • Find the domain that makes physical/practical sense
3

Linear & Quadratic Functions

Modeling with lines and parabolas; analyzing their graphs and solving inequalities.

3.1Properties of Linear Functions▶

Key Concepts

  • Linear: f(x) = mx + b; slope m = rise/run = Δy/Δx
  • Positive slope → increasing; Negative → decreasing; m = 0 → constant
  • Average rate of change = slope between two points
Slope Formulas

m = (y₂ − y₁)/(x₂ − x₁)
Point-slope: y − y₁ = m(x − x₁)

3.2Building Linear Models from Data▶

Key Concepts

  • Scatter plots: plot data, look for linear pattern
  • Line of best fit (linear regression): minimizes error
  • Interpret slope and y-intercept in context
3.3Quadratic Functions & Their Properties▶

Key Concepts

  • Standard: f(x) = ax² + bx + c; Vertex form: f(x) = a(x−h)² + k
  • Vertex: (h, k) = (−b/2a, f(−b/2a))
  • a > 0 → parabola opens up (min); a < 0 → opens down (max)
  • Axis of symmetry: x = −b/(2a)
  • x-intercepts via quadratic formula, factoring, or completing the square
Quadratic Formula

x = [−b ± √(b² − 4ac)] / 2a
Discriminant: b²−4ac > 0 → 2 real roots; = 0 → 1; < 0 → no real

3.4Building Quadratic Models from Data▶

Key Concepts

  • Quadratic regression: fit a parabola to data
  • Use vertex to find max/min value in context (e.g., max profit, max height)
3.5Inequalities Involving Quadratic Functions▶

Key Concepts

  • Solve f(x) > 0 or f(x) < 0 by finding zeros first, then testing intervals
  • Sign chart: mark zeros, test a value in each interval
  • Write solution in interval notation
💡

Always check whether endpoints are included (≥, ≤) or excluded (>, <) when writing interval notation.

4

Polynomial & Rational Functions

Higher-degree polynomials, rational graphs, zeros, and the Fundamental Theorem of Algebra.

4.1–4.2Polynomial Functions & Graphing▶

Key Concepts

  • Degree n → at most n zeros, n−1 turning points
  • End behavior: determined by leading term axⁿ
  • Even degree, positive a → both ends up; odd degree, positive a → left down, right up
  • Multiplicity: if (x−c)^m is a factor, zero at c has multiplicity m
  • Even multiplicity → graph touches but doesn't cross x-axis; odd → crosses
4.3–4.4Rational Functions & Their Graphs▶

Key Concepts

  • R(x) = p(x)/q(x); domain excludes where q(x) = 0
  • Vertical asymptote: x = c where q(c) = 0 and p(c) ≠ 0
  • Hole: x = c where both p(c) = 0 and q(c) = 0 (cancel the factor)
  • Horizontal asymptote: compare degrees of numerator and denominator
  • Oblique asymptote: if degree(p) = degree(q) + 1 → do polynomial long division
Horizontal Asymptote Rules

deg(p) < deg(q) → y = 0
deg(p) = deg(q) → y = leading coeff ratio
deg(p) > deg(q) → no horizontal asymptote

4.5Polynomial & Rational Inequalities▶

Key Concepts

  • Move everything to one side, factor completely
  • Mark zeros AND vertical asymptotes on a number line
  • Test sign in each interval; asymptotes are never included in solution
4.6Real Zeros of a Polynomial▶

Key Concepts

  • Rational Zeros Theorem: possible rational zeros = ±(factors of constant)/(factors of leading coeff)
  • Synthetic division: test candidates efficiently
  • Remainder Theorem: f(c) = remainder when f(x) ÷ (x−c)
  • Factor Theorem: (x−c) is a factor iff f(c) = 0
  • Descartes' Rule of Signs: count sign changes for + and − real zeros
4.7Complex Zeros; Fundamental Theorem of Algebra▶

Key Concepts

  • FTA: every degree-n polynomial has exactly n zeros (counting multiplicity, complex included)
  • Complex zeros of real polynomials come in conjugate pairs: a+bi and a−bi
  • Use known real zeros to factor down, then solve the remaining quadratic
💡

If you find one complex zero a+bi, immediately write down a−bi as another zero.

5

Exponential & Logarithmic Functions

Transcendental functions, their inverses, properties, and real-world models.

5.1Composite Functions▶

Key Concepts

  • (f ∘ g)(x) = f(g(x)) — apply g first, then f
  • Domain of f ∘ g: start with domain of g, then restrict where g(x) is in domain of f
  • Order matters: f ∘ g ≠ g ∘ f in general
5.2One-to-One & Inverse Functions▶

Key Concepts

  • One-to-one: passes horizontal line test → has an inverse
  • Find inverse: swap x and y, solve for y
  • f(f⁻¹(x)) = x and f⁻¹(f(x)) = x
  • Graph of f⁻¹: reflect graph of f over y = x
5.3Exponential Functions▶

Key Concepts

  • f(x) = aˣ where a > 0, a ≠ 1; domain: all reals; range: (0, ∞)
  • a > 1 → increasing (growth); 0 < a < 1 → decreasing (decay)
  • Always passes through (0, 1); horizontal asymptote at y = 0
  • Natural exponential: f(x) = eˣ where e ≈ 2.718
5.4–5.5Logarithmic Functions & Properties▶

Key Concepts

  • log_a(x) = y ↔ aʸ = x (logs are exponents!)
  • Domain: (0, ∞); Range: all reals; passes through (1, 0)
  • Natural log: ln(x) = log_e(x)
Log Properties (memorize these)

log(MN) = log M + log N
log(M/N) = log M − log N
log(Mʳ) = r·log M
Change of base: log_a(x) = ln(x)/ln(a)

5.6Exponential & Log Equations▶

Key Concepts

  • Exponential equation: isolate the base, then take log of both sides
  • Log equation: condense logs, convert to exponential form, solve
  • Always check for extraneous solutions (log domain is x > 0)
💡

Strategy: exponential → log both sides; log equation → exponentiate both sides.

5.7–5.8Financial Models & Growth/Decay▶
Key Formulas

Compound interest: A = P(1 + r/n)^(nt)
Continuous: A = Pe^(rt)
Exponential growth/decay: A = A₀·e^(kt)
Half-life: A = A₀·(1/2)^(t/h)

  • k > 0 → growth; k < 0 → decay
  • Newton's Law of Cooling: T(t) = (T₀ − Tₘ)e^(kt) + Tₘ

A Preview of Calculus: Limits

Introduction to limits, continuity, derivatives, and integrals — the bridge to calculus.

14.1Investigating Limits Using Tables & Graphs▶

Key Concepts

  • lim[x→c] f(x) = L means f(x) gets close to L as x approaches c
  • The limit asks "what value is f approaching?" — not what f(c) equals
  • Limit may exist even if f(c) is undefined
  • Use table of values approaching c from both sides to estimate limit
14.2Algebraic Techniques for Finding Limits▶

Techniques

  • Direct substitution: if f(c) is defined, the answer is f(c)
  • Factor & cancel: factor numerator/denominator, cancel common factor, then substitute
  • Rationalize: multiply by conjugate when square roots are involved
  • Limits at infinity: divide by highest power of x in denominator
Limit Laws

lim(f ± g) = lim f ± lim g
lim(f · g) = lim f · lim g
lim(f/g) = lim f / lim g (if lim g ≠ 0)

14.3One-Sided Limits & Continuity▶

Key Concepts

  • lim[x→c⁻] f(x): left-hand limit (approach from left)
  • lim[x→c⁺] f(x): right-hand limit (approach from right)
  • Two-sided limit exists iff left limit = right limit
  • Continuity at c: f(c) defined, limit exists, and lim = f(c)
  • Types of discontinuity: removable (hole), jump, infinite (asymptote)
💡

Polynomials are always continuous. Rationals are continuous everywhere except where the denominator = 0.

14.4The Tangent Problem & The Derivative▶

Key Concepts

  • Secant line slope approaches tangent line slope as h → 0
  • The derivative f'(c) = the slope of the tangent at x = c
  • Derivative = instantaneous rate of change
Derivative Definition

f'(x) = lim[h→0] [f(x+h) − f(x)] / h

14.5The Area Problem & The Integral▶

Key Concepts

  • Area under a curve approximated by rectangles (Riemann sums)
  • More rectangles → better approximation
  • The definite integral = exact area as number of rectangles → ∞
  • ∫_a^b f(x)dx = limit of Riemann sum
📌

This chapter is just an introduction — know the concepts and limit definitions. Computation comes in Calc 1.
